# Notebooks

Jupyter and Google Colab notebooks for exploration and training.

## Planned Notebooks

1. `01_model_exploration.ipynb` — Load Gemma 4, inspect architecture, test inference
2. `02_data_exploration.ipynb` — Explore candidate datasets, tokenization statistics
3. `03_training_colab.ipynb` — End-to-end QLoRA fine-tuning on Google Colab
4. `04_evaluation_results.ipynb` — Benchmark comparison and visualization

## Colab Usage

All notebooks are designed to be Colab-ready. Open in Colab and ensure
you select a GPU runtime (T4 for E4B, A100 for 12B+).
