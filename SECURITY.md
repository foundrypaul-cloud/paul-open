# Security Policy

## Supported Versions

Only the current main branch of the repository is actively supported for security updates.

## Reporting a Vulnerability

We take the security of our research environment seriously. Please distinguish between the following categories when reporting an issue:

A. **Conventional software vulnerabilities** (e.g., dependency exploits, arbitrary code execution)
B. **Credential/secrets exposure**
C. **Malicious repository modifications**
D. **Dataset poisoning or malicious training data**
E. **Model/evaluation manipulation**
F. **Responsible disclosure of security-sensitive AI behavior**

**Do not publicly expose credentials, API keys, or sensitive security information through GitHub issues.**
**Do not publicly disclose exploit details or instructions for manipulation.**

If enabled for this repository, GitHub's private vulnerability reporting or security advisory mechanisms may be used to report security-sensitive issues securely. Otherwise, please use an established project contact point available through the repository.
